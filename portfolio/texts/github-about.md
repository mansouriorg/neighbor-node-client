# Neighbor Node: GitHub About text

The short text and the topics for the About box of the repository (the gear icon on the repository page).

## About

A help and lending board for neighbors, built with Next.js and TypeScript. No accounts: each post has a private edit link. Replies and reports are private, public actions have speed limits, and posts live in one JSON file. An early version with 125 test files.
