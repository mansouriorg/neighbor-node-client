# Neighbor Node: cover letter pitch

A short paragraph about the project for a cover letter or an e-mail.

## Pitch

I built Neighbor Node, a help and lending board for neighbors, with Next.js and TypeScript. It has no accounts: each post gets a private link, and the server checks every rule again. The project comes with 1,068 tests in 125 test files and a README that says plainly what is still missing. I built it with the help of an AI assistant, and the case study says what I decided and what the assistant wrote. I would like to bring the same care to a team that builds web products.

## Notes

The pitch names no company and no role, so it fits any letter. Its last sentence is general on purpose: it makes no claim about a company that the text cannot know.
