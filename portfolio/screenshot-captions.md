## Architecture diagram

- File: `screenshots/architecture-diagram.png`
- Size: 2400 by 1240 pixels, 189 KB
- Caption: How the parts of Neighbor Node fit together: the pages, the server actions, the rules, the store and the posts file.
- Alt text: A diagram with boxes and arrows. The visitor's browser opens the pages in app. A form sends its data to a server action. The server action asks the rules in lib, which include the speed limits that live in memory, and the key check. The post store writes the posts file data/posts.json. A moderation script reads and changes the same file.

    ![How the parts of Neighbor Node fit together: the pages, the server actions, the rules, the store and the posts file.](portfolio/screenshots/architecture-diagram.png)
